# Connected Textures — Build Without Grid Lines

Connected Textures 9minecraft Mod cleans up the look of your building blocks. It makes items like glass, bookshelves, and sandstone blend together without those annoying grid lines in the middle. This mod changes only how things look on your screen, so you can play with it safely on normal multiplayer servers.

No More Grids: Removes the borders between identical blocks so they look like one large piece. Works on servers because it only changes the graphics on your own screen.

## What this build is

An unofficial rebuild of **TeamCoFH**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
